# Сертификаты

Как добавить новый — два шага.

**1. Положить файл сюда**, в `public/data/certificates/`.
Имя латиницей, без пробелов: `derma-2024.jpg`. Подходят `.jpg`, `.png`,
`.webp`. Ориентация любая: и вертикальные, и горизонтальные документы
показываются целиком, без обрезки.

**2. Добавить запись** в `public/data/text/data.json`, блок `certificates.items`:

```json
{
  "image": "/data/certificates/derma-2024.jpg",
  "title": "Клиническая дерматология",
  "issuer": "КГМА им. И. К. Ахунбаева",
  "date": "2024"
}
```

`title` — за что выдан, `date` — когда (год или «Март 2024»).
`issuer` и `date` необязательные: если их нет, строки просто не появятся.

Карточек может быть сколько угодно — они сами встают в сетку по три в ряд
(две на планшете, одна на телефоне).

Те же записи стоит продублировать в `english-data.json` и `kg-data.json` —
это тексты для английской и кыргызской версий сайта. Путь к картинке в них
тот же, переводятся только `title` и `issuer`.

Пока список `items` пустой, раздела «Сертификаты» на сайте нет — пустой
блок с заголовком выглядел бы как недоделанная страница.
